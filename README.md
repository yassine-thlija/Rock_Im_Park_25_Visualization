# ⚡ Rock Im Park 2025: Lineup Visualization ⚡  
### Shredding the lineup into data — one band, one genre, one day at a time.

Get an interactive, headbang-worthy look at the full **Rock im Park 2025** lineup — visualized with nodes, genres, and gig dates. Think of it as a mosh pit of data structures, color-coded and ready to rage.

## 🔥 What's Inside  
This repo is packed with three power-chords of content:

- 🎸 `RIP.md`  
  Raw festival data, organized in markdown tables like a digital tour poster.
